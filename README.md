# AI Interview Trainer Agent

AI-powered Interview Trainer built using IBM watsonx.ai and Llama 3.

This project helps students and job seekers practice technical interviews by generating AI-based interview questions and evaluating answers professionally.

---

# Features

- AI-generated interview questions
- Skill-based interview preparation
- Difficulty selection (Easy / Medium / Hard)
- AI answer evaluation
- Professional feedback system
- Modern React frontend
- FastAPI backend
- IBM watsonx.ai integration
- Llama 3 foundation model
